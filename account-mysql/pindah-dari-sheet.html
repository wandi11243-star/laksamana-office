Pindahkan Daftar User dari Google Sheet

Menyalin isi tab Users, Modules, Grants, dan Admins dari Apps Script lama ke database account. Dijalankan sekali. Aman diulang kalau terputus.

PIN Anda tidak dikirim ke mana pun selain kedua server itu sendiri. Halaman ini berjalan di browser Anda; PIN dipakai untuk membuktikan ke Apps Script dan ke server account bahwa Anda memang superadmin. Tidak ada yang disimpan.

1 Kredensial untuk membaca Sheet

Akun superadmin Office Anda, dengan PIN yang sekarang dipakai sehari-hari.

2 Kredensial untuk menulis ke database baru

Ini biasanya BERBEDA dari yang di atas. Database baru masih berisi akun benih (Admin / Howandi / Wandi dengan PIN 1111), sedangkan PIN asli Anda baru akan berlaku setelah pemindahan ini selesai. Jadi di sini pakai akun benihnya.

Halaman ini diletakkan di dalam folder account-api-mysql/, jadi ./api.php sudah tepat.

3 Periksa dulu, baru pindahkan

4 Setelah selesai

Hapus berkas pindah-dari-sheet.html ini dari server setelah dipakai. Lalu buka ?action=stats untuk memastikan jumlah user-nya sudah sesuai, dan coba login dengan akun asli Anda.
